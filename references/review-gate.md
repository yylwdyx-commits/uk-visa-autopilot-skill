# 审查团队操作办法（递交前评审闸）

**目的**：在点提交之前，用一支模拟的「签证官 + 移民律师 + 审计 + 编辑」团队把整套材料撕一遍，把会导致拒签或构成 misrepresentation 的问题在递交前抓出来。英国线实跑一次：21 个 agent，确认 13 条（5 blocker + 8 major），推翻 4 条，minor 20 条，全部整改后递交，获批 10 年。

**原则**：不默认达标。每一条 blocker/major 都必须**回原始证据**（签证页实拍、资产证明原件、文件原文）人工复核后再整改；评审只负责提出，判定归证据。

## 一、输入
- 全套成品：答案册（逐题答案）、说明信、在职证明、行程单、材料清单、审核标准自检表。
- 全部支撑证据的原件或实拍：护照信息页与所有签证页、出入境记录、流水、资产证明、营业执照、工商公示截图。
- 申请人已拍板的决定清单（哪些是有意为之，评审不该反复提）。

## 二、四个视角，并行各派 agent（每视角 3~5 个，互不通气）

| 视角 | 扮演 | 任务 | 交付 |
|---|---|---|---|
| A 审签官 | UKVI 签证官，目标是找拒签理由 | 按 Appendix V 4.2 三问（会不会走 / 钱够不够来路净不净 / 说的和证的对不对得上）逐条挑 | 每条：拒因 → 依据哪一段材料 → 严重度 |
| B 移民律师 | 申请人自己请的律师，目标是防 misrepresentation | 把每一句陈述和随信提交的证据并排对，找"信里说 X、证据印着 Y"；找表演式坦白、元叙述、责任口径漂移 | 每条：陈述原句 → 冲突证据 → 若被查出的后果 |
| C 一致性审计 | 只对字段不看故事 | 姓名拼写（对 MRZ）、日期、地址、同行人、四个钱数（年收入/存款/月支出/旅费）在表、流水、在职、说明信、官方记录五处交叉 | 差异表：字段 / 出处 1 / 出处 2 / 谁对 |
| D 英文文书 | 母语编辑 + 使馆文书经验 | 语法、律师腔、悬空语法、语序；删自我贬损、删多余修辞、保留事实 | 逐句改稿 + 改动理由 |

每个 agent 的输出统一格式：`级别(blocker/major/minor) | 位置(文件:段落) | 问题 | 证据 | 建议改法`。
- **blocker**：递交即构成 misrepresentation 敞口或买错产品（例如信里的日期与自交证据打架、申 10 年却零处论证需要常来）。
- **major**：明显拉低过签概率或口径漂移。
- **minor**：润色、去重、格式。

## 三、反方核验（每条 blocker/major 必派）
对每条 blocker/major，另派一名「反方律师」agent，任务只有一个：**尽力推翻这条发现**——找出它读错了哪份材料、忽略了哪个上下文、或者改了反而更糟。反方给出：`维持 / 推翻 / 降级` + 理由。
- 维持 → 进整改清单。
- 推翻 → 记进「评审提出但明确不改」，写明推翻理由，防止下一轮再提。
- 降级 → 按新级别处理。

## 四、整改与回证据
1. 每条维持的发现，先**开原件**看一眼再改（不是看档案里的叙述）。踩过：档案叙述里家人的获签时间与签证页实拍差了数年——差一点把错日期写进主申请信。
2. 改完把改动写进成品的「我改了什么」段，让申请人能否决。
3. 数字类整改（存款、年收入、月支出、旅费）统一口径：**单件证明能证多少填多少，绝不多件相加**；年收入从流水反推，不拍脑袋。
4. 明确不改的条目写进自检表，附理由（成本>收益 / 跨申请口径一致是资产 / 申请人已拍板）。

## 五、交表闸门（全绿才递）
| # | 检查 | 判据 |
|---|---|---|
| 1 | 多份表交叉一致 | 地址/日期/同行人/资金口径逐字一致 |
| 2 | 五处数字对齐 | 表 = 流水 = 存款证明 = 在职证明 = 说明信 |
| 3 | 姓名拼写 | 与各自护照 MRZ 逐字符一致 |
| 4 | 流水红线 | 无近 60 天不明大额入账，或已备来源证明 |
| 5 | 拒签申报 | 有史者勾 Yes + 解释信在附件列表里 |
| 6 | 附件清单 | 对照材料清单逐项打勾，官方出入境记录在内 |
| 7 | 时效 | 所有材料距递交日 ≤ 6 个月，存款冻结覆盖到回程之后 |
| 8 | 评审闸 | 所有 blocker/major 已整改或已被反方推翻并记录 |

## 六、这次实跑抓到的典型问题（脱敏，供校准严重度）
| 级别 | 问题类型 | 改法 |
|---|---|---|
| blocker | 说明信写家人的签证"granted in <年月>"，随信提交的签证页印着另一年份——信与自交证据当场打架 | 改成签证页上的真实签发/到期日，并加"已持有 N 年、合规使用 M 次"，反而更硬 |
| blocker | 说明信里的家庭/同行人数与所述事件当时的实际人数不符，表里生日一对就是编造嫌疑 | 改成事件当时的真实人数；"代办全家的申请"改"代办我的申请" |
| major | 申 10 年签却零处论证"需要经常来"，反而强调"从没去过"＝教科书降签画像 | 每封信加一段：官方记录背书的年均出行频次 + 留给下次的目的地 + 今后定期来 |
| major | 答案册残留早期"2 年 £xxx"的旧拍板，照抄＝买错产品不可退 | 全文扫成最终产品口径 |
| major | 把某国签证的获签月份写成出行月份，五眼共享数据可证伪 | 删获签月份，只锚定官方记录能证的出行日期 |
| major | "first trip on our own since children born"大概率不实 | 软化为"one of the very few" |
| major | 表格里的雇佣身份与信件里的公司所有权表述不一致，工商公示可交叉验证 | 全套统一为工商登记能证实的口径，删所有权暗示 |
| major | 学校证明模板写"随父母出行"，照抄开出＝书面证明孩子同行，与"孩子留在家"矛盾 | 模板作废；真要开只开纯在读证明 |
| major | 表演式坦白与所附记录不符（出入境记录里本来没有拒签信息） | 删修辞留事实 |
| 推翻 | 在职证明某处措辞被要求重盖 | 字面为真，够不到欺骗条款；已盖章，重盖成本>收益 |
| 推翻 | 拒签原因的叙事被要求重写 | 信里已把责任揽回自己；与上一次申请口径一致是资产，重写反而制造漂移 |

## 七、成本
21 个 agent 一轮约一小时，token 开销可观，但这是整条链上唯一能在递交前把 misrepresentation 抓出来的环节。递交后没有撤回不留痕的办法。
